## Parte 2 — Os defeitos que estavam armados

Todos pré-existentes, todos silenciosos, todos corrigidos em 12–13/09.

### 1. O gravador mandava o Senador para a chave do Presidente

`cargoFromTseNumeric` era `cargoTse === 3 ? "gov" : "pres"`, escrito quando a eleição tinha dois
cargos. Com Senador (5) e Deputado (6) na tabela desde 11/09, **todo payload de cargo 5 ia para
`projection-current-pres-t1`** — chave válida, JSON válido, eleição errada, nenhum erro.

O outro lado: `/senador` lê `projection-current-sen-t1`, chave que nunca era escrita. A tela de
Senador, entregue em 11/09 com gate de a11y PASS, **nunca teria dado em produção**.

**Estava armado para disparar quando o usuário colasse o `EDGE_CONFIG_TOKEN`** — sem credencial,
`writeEdgePayload` é no-op. Corrigido antes de o token existir.

### 2. A função de alarme se derrubava sozinha

`_alert_slack` chamava `_log(level, msg, msg=...)` — `TypeError` — sempre que `SLACK_WEBHOOK_URL`
está ausente. A função que promete nunca levantar levantava, em todo ambiente sem Slack,
**exatamente no momento em que um alerta disparava**, derrubando o ciclo junto.

### 3. As telas chamavam de projeção o que não é

As duas telas de Deputado diziam "Projeção Atlas Menna" e montavam `<ForecastTransparency>`, que
calcula `pctModel = 100 − pctApurado`: com 71,4% apurado ele imprimia **"Modelo 28,6%"**,
atribuindo 28,6% da bancada a um modelo que não existe. Substituído por
`components/blocks/DeputadoMetodologia.tsx`, sem tocar o componente compartilhado (serve 3 rotas).

### 4. A produção estava em 17/05 — e por dois motivos independentes

**Causa A: uma rolling release parada há 4 meses.** Configuração 10% → 50% → 100%, os dois
primeiros com **aprovação manual**. Uma release começou em **17/05 06:58**, parou nos 10%
esperando um clique que nunca veio, e **toda publicação posterior entrou em fila**.

**Causa B: o GitHub App da Vercel não estava instalado.** `github.com/settings/installations`
dizia "No installed GitHub Apps". A autorização OAuth continuava lá — por isso login e painel
funcionavam. **Identificar o usuário e ler o repositório são permissões diferentes.**

⚠️ **Instalar o app não bastou.** São duas camadas: o app instalado (acesso ao repositório) e o
webhook do projeto (avisa do push). Depois de instalar, a Vercel já enxergava o repositório e um
push **não disparou build por 18 minutos**. `vercel git connect` respondeu *"already connected"* e
não fez nada. Só `vercel git disconnect` **seguido de** `connect` refez o webhook.

## Parte 3 — O que a tela de Deputado NÃO faz, e diz que não faz

**Não é projeção.** O número é a distribuição de cadeiras do ADR-0027 sobre os votos **já
apurados** — "como ficaria a bancada se a contagem parasse agora".

Para projetar, falta o **bootstrap de voto por agremiação**, que não existe para o cargo 6
(`extrapolation.py` resampleia candidato-por-zona, para majoritário). É a mesma peça que falta
para o intervalo de RF-127.

**O custo foi medido e cabe** (`scripts/bench-deputado.py`): ciclo das 27 UFs em **20,5 ms**;
redistribuição de cadeiras sobre 1.000 resamples × 27 UFs em **11,1 s**, contra teto de 60 s. O
obstáculo nunca foi CPU — é modelagem.

Até lá, o que sai de RF-127 é a **marcação**: cadeira ganha em rodada de sobra com margem apertada
vai como `indefinido`, e a tela diz isso em texto.

## Comandos

⚠️ **`pnpm test -- <arquivo>` NÃO filtra — roda a suíte inteira.** O `--` não é consumido pelo
pnpm: chega ao vitest como argumento (`vitest run -- tests/...`) e o filtro posicional não se
aplica. **A forma que filtra é `pnpm exec vitest run <caminho>`** (ou `npx vitest run <caminho>`).

Medido em 13/09, lado a lado: a forma correta leva **0,72 s** (1 arquivo, 66 testes); a forma com
`--` não terminou em 40 s. E a prova não é a duração — é o conteúdo do log: apareceram
`model_project_ok` e `zona_merge`, de testes de **integração** que o arquivo pedido não contém.

Custou uma madrugada a uma sessão paralela, que passou horas convencida de estar rodando alvos
isolados enquanto disputava o mesmo Neon de dev com outra. Nada no output acusa — o único sinal é
o tempo, que se lê como "a suíte é lenta mesmo", o que ela de fato é.
